Read the experiment

A small brand, a broad test.

Night Lab is fictional. The owl, mug, teal-and-amber palette and “ideas after dark” theme give the models recurring visual constraints. The images are test assets, not a real business or a claim of brand ownership.

The starting point was OpenAI’s Image 2.6 launch video and its launch article. The experiment translates their features into inspectable API requests. All media on this page already exists; browsing makes no API calls.

A feature tour, not a statistical benchmark. Each setting has one sample. There is no fixed seed, and the speed test does not include an older-generation model.

Two variants / outputs 01–02

Change the model. Keep the brief.

Both requests use the same text, 1024×1024 dimensions, low quality and low complexity. Flare is positioned for fast iteration; Sunburst for detailed visual work. These two files let you examine the actual difference on one scene.

Observed: Flare took 7.376 seconds; Sunburst took 11.734 seconds. Both cost $0.025495. The compositions, owl designs and wordmarks also vary. One pair cannot prove a universal speed advantage.

Planning / outputs 07–09

Complexity is a different control.

quality

How much rendering fidelity to request.

complexity

How much planning to request before rendering.

A checkable infographic brief asks for exactly six boxes, two rows, five specified arrows, exact labels and a repeating teal/amber/cream color assignment. The model and high quality stay fixed; only complexity changes.

Observed: all three satisfy the principal box, label, color and connection constraints on visual inspection. Each cost $0.053540. High complexity took longer, but it did not solve a visible structural failure in the lower settings. More planning is a tool to test against a task, not a guarantee of improvement.

Official complexity guidance

Successive edits / outputs 03 → 10 → 11 → 12

Follow one scene through three changes.

Each edited image becomes the next request’s input. This tests how well a character, product and scene survive an editing chain.

Observed: the scene remains recognizable, but preservation is imperfect. The first edit changes the logo from teal to cream. The lighting edit makes the brass lamp look silver. “Keep everything else” is an instruction to inspect, not an exact pixel lock.

Spatial guidance / outputs 17–18

Point to the change.

Markup is a separate transparent PNG annotation layer. The original scene stays unmarked. Both requests independently start from output 03 and use identical model, prompt, quality and complexity; only one adds the markup input.

  1. Source 03Unmarked original PNG
  2. Transparent overlayRed ellipse around the left mug
  3. Image API editSame text plus the separate markup file
  4. Output 18Recolored scene, annotation absent

The same instruction in both requests

Recolor only the left mug ceramic body cobalt blue. Preserve its NIGHT LAB logo, handle shape, reflections, the other mug, the owl mascot, lamp, notebook and background. Remove any red annotation circle from the finished photograph. Change nothing else.

The actual overlay is mug-markup.png: 1024×1024, with transparent pixels outside the red circle.

There is no exact binary stencil here. The annotation guides the model’s interpretation of the requested change.

Professional visuals / outputs 13–14

Turn a visual brief into a layout.

The ad asks for a left-positioned product and an exact headline. The poster asks for a specific hierarchy of title, date and tagline. Both are new text-to-image requests, rather than reference-preserving edits of the source logo.

Observed: the requested copy is legible and the hierarchy is recognizable. The owl marks differ from those in the original scene. These files showcase layout and typography; they do not demonstrate exact brand-asset reuse.

Reference images and motion / outputs 15–16

A sketch becomes a character, then six poses.

What this exposes: pose continuity, character scale, frame alignment and the return toward the starting pose. Fixed-grid extraction retains any registration errors instead of silently repairing them.

Native vector output / outputs 19–20

Pixels describe it. Vectors make it editable.

With output_format="svg", the image model creates a reference and an SVG authoring model writes the vector document. Both requests use GPT-6 Luna with low reasoning effort as the author; only the image model changes.

What is editable?

Paths, circles, fills, strokes and text. The derived examples change teal fills to purple and enlarge one circle’s radius by 15%. No additional API calls are needed.

What did the API actually return?

Flare: 23 XML elements. Sunburst: 35. Both contain zero embedded raster images. Vector structure is verified separately from visual quality.

Observed limitation: the Flare wordmark clips at the SVG edges in browser rendering. Text uses system fonts rather than outlined glyphs, so font metrics can affect fit. Native vector output still needs production review.

Native animation / outputs 21–22

Ask the API for a finished GIF.

These are native Image API outputs with output_format="gif", frame_count=6, frame_duration_ms=200 and 512×512 frames. Each is an infinite 1.2-second loop. They were generated from text, independently of the earlier reference assets.

Observed: both files contain six correctly timed frames. The owl’s requested spectacles and a clear full blink are missing. The mug’s steam moves while the product remains broadly stable. A valid animated file does not establish that every requested motion or detail is present.

The API returns the finished GIF, not an exposed intermediate sprite sheet. The decoded frame folders preserve the returned animation. Output 16 is the separate, inspectable sprite-sheet experiment.

What did the run cost?

$1.163287 calculated from returned token usage. The experiment used a $4 allocation. Image rates in the saved snapshot are $5 per million text-input tokens, $8 per million image-input tokens and $30 per million image-output tokens. SVG author usage is added separately. This is usage-based arithmetic, not an invoice reconciliation.

One initial SVG request omitted svg.model and received HTTP 400 with no usage. The corrected request is saved as attempt 02. The rejected request is recorded at $0.

What is public?

Generated media, relative paths, prompts, settings, elapsed timings, usage and costs. Account identifiers, request identifiers, exact activity timestamps, personal setup notes, credentials and private local paths are omitted. The source video and launch article are linked rather than republished.

The site is static, uses local assets, and loads no analytics, external fonts or API credentials. Animation plays only when you choose it.

The runner’s local spending reserve is not a provider-enforced dollar cap. Timings are single-trial end-to-end measurements. Generated text, exact preservation and animation details need human review.
